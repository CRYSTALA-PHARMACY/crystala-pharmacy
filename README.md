# CRYSTALA PHARMACY — الموقع التعريفي v2 (GitHub Pages)

موقع تعريفي عربي (RTL) كامل لنظام إدارة الصيدليات — جاهز للنشر على GitHub Pages بدون أي أدوات بناء.

## محتويات المجلد

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الرئيسية: 14 وحدة، مميزات بالتفصيل، بنية الشبكة، الأمان، التقنيات، التحميل، الأسعار والمقارنة، دليل البدء، 13 سؤالاً شائعاً |
| `eula.html` | اتفاقية الترخيص (EULA) — محدثة بأنواع التراخيص وحدود المستخدمين وفترات السماح |
| `privacy.html` | بيان حماية البيانات — توثيق أن النظام يعمل محلياً بالكامل |
| `404.html` | صفحة الخطأ 404 |
| `css/style.css` | التصميم الكامل — الهوية مستخرجة من التطبيق نفسه (Cairo + ألوان البلورة) |
| `js/main.js` | **كائن CONFIG: كل ما ستعدّله مستقبلاً (روابط التحميل، البصمات، التواصل)** |
| `assets/img/` | الشعار والأيقونات (من أصول التطبيق الأصلية) |

## ما الجديد في v2؟

1. **قسم الوحدات الـ14** — تغطية كاملة لكل وحدات النظام بما فيها الولاء، التوصيل، التركيبات المعملية، والتفاعلات الدوائية.
2. **مميزات بالتفصيل** — 6 مجموعات × 3 مميزات بالخامات الحقيقية من وثائق الميزات (GS1 DataMatrix، ربط الروشتة بالفاتورة، الجرد بالمسح…).
3. **قسم الأمان** — TOTP، سجل تدقيق، حماية مستوى قاعدة البيانات، نسخ احتياطي مجدول.
4. **قسم التقنيات** — PostgreSQL 17، .NET 10، Blazor WASM، SignalR، CefSharp، ZXing.
5. **أسعار مصححة ومطابقة لمولّد التراخيص** — التجريبية 3 مستخدمين، الشهرية 5، السنوية 8، الدائمة 12 + فترات السماح + جدول مقارنة تفصيلي.
6. **بنية شبكة تفاعلية** — مخطط الماستر والعملاء مع اكتشاف UDP.
7. **محاكاة واجهة POS** في الهيرو بـCSS خالص + عدادات متحركة + شريط تقدم قراءة + تمييز القسم النشط + زر عودة للأعلى.
8. **FAQ موسع** إلى 13 سؤالاً (أُضيف: حد المستخدمين، انتهاء الاشتراك، الربطات الرسمية، الترحيل).

## النشر على GitHub Pages (3 دقائق)

1. أنشئ مستودعاً جديداً باسم `crystala-pharmacy` (أو أي اسم) واجعله **Public**.
2. ارفع محتويات هذا المجلد كاملة إلى المستودع (ملفات في الجذر مباشرة، لا داخل مجلد فرعي).
3. من إعدادات المستودع: **Settings → Pages → Source: Deploy from a branch → Branch: main / (root)** ثم Save.
4. بعد دقيقة سيعمل الموقع على: `https://USERNAME.github.io/crystala-pharmacy/`
5. (اختياري) لربط دومين خاص: أضف ملف `CNAME` يحتوي اسم الدومين، ومن مزود الدومين أضف سجل `CNAME` يشير إلى `USERNAME.github.io`.

> **ملاحظة SEO:** بعد النشر أضف رابط موقعك إلى Google Search Console لتفعيل الأرشفة السريعة.

## التحديثات الروتينية

### تحديث روابط التحميل بعد الانتقال إلى GitHub Releases

كل الروابط والبصمات في مكان واحد أعلى `js/main.js` داخل كائن `CONFIG.downloads`:

```js
{
  id: 'master',
  ...
  filename: 'CRYSTALA-PHARMACY-Setup-1.6.4-Clean.exe',
  sha256: 'e5c0c3052071f05c...',   // بصمة الملف الجديد
  url: 'https://github.com/USER/REPO/releases/download/v1.6.4/CRYSTALA-PHARMACY-Setup-1.6.4-Clean.exe',
}
```

استبدل قيمة `url` بالرابط الجديد وقيمة `sha256` ببصمة الملف الجديد — البطاقات تُبنى تلقائياً في الصفحة.

### تحديث بيانات التواصل

في نفس الملف `js/main.js` داخل `CONFIG.contact`:

```js
contact: {
  whatsapp: { label: 'واتساب المبيعات والدعم', value: '0121 162 9768', href: 'https://wa.me/201211629768' },
  email:    { label: 'البريد الإلكتروني', value: 'crystala.erp@gmail.com', href: 'mailto:crystala.erp@gmail.com' },
  support:  { label: 'الدعم الفني (عن بُعد)', value: 'جلسات AnyDesk / TeamViewer بالتنسيق', href: 'https://wa.me/201211629768' }
}
```

### تحديث الأسعار لو تغيّرت

الأسعار موجودة في `index.html` داخل قسم `#pricing`:
- بطاقات الباقات الأربع (ابحث عن `plan__price`).
- جدول المقارنة التفصيلي (ابحث عن `compare__table`).

> **مهم:** عند تغيير أي بند تعاقدي (مستخدمون/سماح/تحديثات) طابقه مع مولّد التراخيص —
> القيم المرجعية الحالية: تجريبي (30 يوم/3 مستخدمين/بلا سماح)، شهري (30/5/7 أيام)،
> سنوي (365/8/7 أيام)، دائم (بلا انتهاء/12/تحديثات 12 شهراً).
